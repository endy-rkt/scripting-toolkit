# scripting-toolkit

A collection of cross-platform automation, networking, and security scripts — designed for **CTF challenges**, **sysadmin tasks**, **learning**, and **personal use**.

---

## 📁 Project Overview

The **scripting-toolkit** is organized by language, making it easy to explore or extend:

* **bash/** — system and network utilities for Linux environments.
* **python/** — automation, networking, and security tools.
* **powershell/** — Windows system and Active Directory utilities.

---

## ⚙️ Tools & Dependencies

Depending on the language and script, you may need:

**Bash:**

* Core Linux utilities (`grep`, `awk`, `ifconfig`, `lshw`, etc.)

**Python:**

* Python 3.8+
* Recommended modules:

  ```bash
  pip install scapy paramiko
  ```

**PowerShell:**

* PowerShell 7+ (cross-platform) or Windows PowerShell

Some tools (like sniffers or ARP scripts) require root/admin privileges.
